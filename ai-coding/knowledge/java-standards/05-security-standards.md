# 安全规范

## 1. 数据安全

### 1.1 敏感数据处理
- **禁止明文存储**：密码、身份证号、银行卡号必须加密存储
- **脱敏展示**：日志和前端展示时对敏感信息进行脱敏
  ```java
  // 正确：手机号脱敏
  String phone = "13812345678";
  String masked = phone.replaceAll("(\\d{3})\\d{4}(\\d{4})", "$1****$2");
  // 输出：138****5678
  ```

### 1.2 SQL注入防护
- **强制使用预编译**：禁止拼接SQL
  ```java
  // ❌ 错误：存在SQL注入风险
  String sql = "SELECT * FROM user WHERE username = '" + username + "'";
  
  // ✅ 正确：使用PreparedStatement
  String sql = "SELECT * FROM user WHERE username = ?";
  PreparedStatement ps = conn.prepareStatement(sql);
  ps.setString(1, username);
  ```

### 1.3 XSS防护
- **输入验证**：对用户输入进行白名单校验
- **输出转义**：HTML、JavaScript、URL上下文分别转义

## 2. 认证授权

### 2.1 Token管理
- **过期时间**：访问Token 2小时，刷新Token 7天
- **单点登录限制**：同一账号最多5个活跃会话
- **敏感操作二次验证**：修改密码、绑定手机号需验证码

### 2.2 权限控制
- **最小权限原则**：默认无权限，按需分配
- **接口级鉴权**：每个API必须标注权限注解
  ```java
  @RequiresPermissions("user:update")
  @PostMapping("/user/update")
  public Result updateUser(@RequestBody UserDTO user) {
      // ...
  }
  ```

## 3. 接口安全

### 3.1 签名验证
- **请求签名**：关键接口（支付、订单）必须验证签名
- **时间戳校验**：拒绝超过5分钟的请求
- **幂等性保证**：使用唯一请求ID防重放

### 3.2 限流降级
- **接口限流**：QPS限制，超限返回429
- **熔断降级**：故障服务自动熔断
- **黑名单机制**：异常IP自动封禁

## 4. 数据传输

### 4.1 加密传输
- **强制HTTPS**：生产环境禁止HTTP
- **证书管理**：使用正规CA证书，定期更新

### 4.2 文件上传
- **格式校验**：白名单验证文件类型
- **大小限制**：单文件不超过10MB
- **病毒扫描**：上传文件自动扫描

## 5. 日志安全

### 5.1 敏感信息过滤
- **禁止记录**：密码、完整身份证号、完整银行卡号
- **脱敏记录**：手机号、姓名、地址等部分脱敏

### 5.2 审计日志
- **关键操作留痕**：登录、支付、数据修改等
- **保留周期**：审计日志保留180天

## 6. 依赖安全

### 6.1 组件管理
- **漏洞扫描**：定期扫描第三方依赖漏洞
- **版本控制**：禁止使用存在高危漏洞的版本
- **来源可信**：仅使用Maven Central等官方仓库

### 6.2 许可证合规
- **黑名单**：禁止使用GPL等强传染性协议
- **白名单**：Apache 2.0、MIT、BSD等允许使用

## 7. 应急响应

### 7.1 安全事件处理
- **发现漏洞**：30分钟内上报安全团队
- **紧急修复**：高危漏洞4小时内发布补丁
- **事后复盘**：48小时内完成事件报告

### 7.2 数据备份
- **定期备份**：每日全量备份
- **异地容灾**：关键数据双机房备份
- **恢复演练**：季度进行恢复演练

## 8. 禁止事项

### 8.1 硬编码敏感信息
- ❌ 禁止：代码中硬编码密码、密钥、Token
- ✅ 正确：使用配置中心或密钥管理系统

### 8.2 越权操作
- ❌ 禁止：通过修改ID访问他人数据
- ✅ 正确：验证当前用户与目标资源的归属关系

### 8.3 调试代码上线
- ❌ 禁止：System.out.println、printStackTrace上线
- ✅ 正确：使用日志框架，生产环境关闭DEBUG级别
